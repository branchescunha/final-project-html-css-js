# Final Project HTML, CSS and JavaScript

Landing page de portfólio pessoal com gerenciamento de tarefas, desenvolvida como projeto final de HTML, CSS e JavaScript.

## Funcionalidades

- Apresentação pessoal
- Tema claro e escuro
- Alternância de tema com ícones de lua e sol
- Cadastro de tarefas
- Prioridades baixa, média e alta
- Conclusão e remoção de tarefas
- Contador de tarefas pendentes
- Filtros por status
- Ordenação por prioridade
- Edição por duplo clique
- Persistência com localStorage
- Formulário de contato
- Layout responsivo

## Tecnologias

- HTML5
- CSS3
- JavaScript
